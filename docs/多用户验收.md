# 多用户验收

2026-11-03 验证范围：独立账号隔离、50 用户、20 个执行同时状态。团队空间、共享群聊及角色权限属于后续功能。

## 本次改动

- 群聊列表将逐群查询改为批量查询，数据库查询数量不随群聊数逐条增加。
- 普通账号的状态日志与 Prometheus 指标只返回自身数据；部署日志和系统告警由 `BOTLY_ADMIN_EMAILS` 配置的管理员查看。
- Worker 的数据库认领保证全局 20、每用户 2 的并发上限，多进程不能重复认领。
- 修复 Postgres 检查点首次并发初始化的建表竞态；SDK 的并发索引创建使用非阻塞尝试锁，避免与等待锁的语句快照形成死锁。
- 不同部署可通过 `BOTLY_REDIS_PREFIX` 隔离队列，测试实例不消费业务实例的任务。
- 账号彻底清除补齐 OAuth 绑定、MCP、技能和记忆候选数据。

## 环境与结果

独立临时 Postgres 数据库，本机 API 与真实 Worker 进程，Redis 不可用时的数据库轮询路径；每账号自己的 Cookie、mock 模型和群聊，50 个群聊各播种 1000 条消息。模型为离线 mock，不代表真实厂商吞吐或费用。

| 项目 | 结果 |
| --- | --- |
| 用户 | 50 |
| 完成执行 | 50 / 50 |
| 同时状态峰值 | 20 |
| 账号隔离检查 | 350 项通过 |
| 首屏消息接口，200 请求（最终回归） | p50 197.2ms / p95 336.4ms / p99 425.0ms |
| 群聊列表接口，200 请求（最终回归） | p50 193.2ms / p95 391.9ms / p99 507.2ms |
| 执行阶段耗时 | 13.6 秒 |

此为后端接口和执行容量验收，首屏浏览器渲染、真实模型延迟、远端沙箱容量需在部署环境另行验证。此次记录时的 Postgres SSE 提交顺序残留，已在 2026-11-04 收尾中通过提交阶段分配事件 ID 与用户事务锁处理。

首次独立验收的消息/群聊 p95 为 131.0ms / 164.3ms；最终回归同时进行后端测试，机器负载更高，仍通过 50 用户 / 20 并发与全部隔离检查。

## 复跑

在独立测试环境中让 API、Worker 与脚本使用相同的 `DATABASE_URL`、数据目录及 Redis 前缀；不使用生产数据库：

```bash
cd server
./venv/bin/python -m scripts.loadtest --base http://127.0.0.1:8200 \
  --users 50 --concurrency 20 --requests 200 --messages 1000 \
  --output /tmp/botly-multiuser-report.json
```

本机已有独立测试 Postgres（55432）时，启动器会创建新测试库、启动测试 API 和 Worker，并在结束后停止测试进程：

```bash
./venv/bin/python -m scripts.verify_multiuser
```

脚本创建唯一前缀的测试账号并保留测试库供排查；不会覆盖已有账号。SQLAlchemy 使用 Postgres，LangGraph 使用同一库的检查点表。输出 JSON 可用于比较后续改动。

## 2026-11-04 高危修复后回归

负载脚本现在直接在独立测试库预置账号，再通过真实登录接口取得各自的 Cookie，避免同一台负载机批量注册触发按 IP 限流；注册、登录、邮件接口的限流与伪造 XFF 防护由安全回归测试单独覆盖。

| 项目 | 结果 |
| --- | --- |
| 用户 / 完成执行 | 50 / 50 |
| 同时状态峰值 | 20 |
| 账号隔离检查 | 350 项通过 |
| 消息接口，200 请求 | p50 62.6ms / p95 85.0ms / p99 90.5ms |
| 群聊列表，200 请求 | p50 50.3ms / p95 119.4ms / p99 122.5ms |
| 执行阶段耗时 | 11.9 秒 |

环境为本机独立临时 Postgres 18、API 与 Worker、Redis 降级路径和 mock 模型；每群聊仍预置 1000 条消息。此表保留独立回归结果，不直接用不同机器负载下的数值计算性能提升比例。

2026-11-04 收尾后的独立验收已在用户要求停止测试前完成：50/50 执行完成、并发峰值 20、350 项隔离检查通过；消息接口 p95 147.8ms，群聊列表 p95 231.1ms，执行阶段 14.9 秒。结果来自当时本机负载，使用 mock 模型。后续按用户要求不再追加测试。
