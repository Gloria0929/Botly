## 5. 体验残留（功能可用，但有明确短板）

| 项 | 说明 |
| --- | --- |
| 免密钥搜索质量 | DuckDuckGo 回退无摘要（只有标题 + 链接），反爬时返回 202/空页只能报失败；要稳定需配 Tavily Key |
| `web_read` 空壳站点 | Reddit / 知乎等对非浏览器请求返回外壳，正文 < 120 字会提示失败；没有渲染服务或第三方提取 API 兜底 |
| 审批过期的语义 | 过期交回总指挥，但只有「工具未执行」结果，没有结构化「拒绝」字段，审计只能靠审批状态区分 |
| 改派次数识别（RUN-10） | 依赖模型回传计划 `step`；不回传时按指令文本匹配，改写说法仍可能绕过 |
| 执行中停用 Bot | 不会打断正在跑的那一轮，只在下一轮生效 |
| 并行子任务文件冲突 | 2026-11-04 已优化：新任务默认独立目录，文件工具阻止跨任务写入，Cube 同步保留其他任务新文件；Shell 显式共享绝对路径仍需协调 |
| 邮箱验证不阻断 | 未验证邮箱也能正常使用（邀请制第一版的有意取舍） |
| Web Push 限制 | 要求 HTTPS（localhost 除外）；iOS 16.4+ 需添加到主屏幕；多实例部署必须显式配置同一把 VAPID 密钥 |
| Postgres 下 SSE 事件顺序 | `events` 自增 id 并发提交时可能乱序，单条事件可能被跳过；前端重连/快照兜底，彻底修复需按群聊分配序号 |
